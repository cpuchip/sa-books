$$\varphi = k \lambda \int_{x-a}^{x-b} \frac{-du}{\sqrt{u^2 + y^2}}$$

Using the minus sign to interchange the limits of integration, we have:

$$\varphi = k \lambda \int_{x-b}^{x-a} \frac{du}{\sqrt{u^2 + y^2}}$$

Using the appropriate integration formula from the formula sheet we obtain:

$$\varphi = k \lambda \ln \left( u + \sqrt{u^2 + y^2} \right) \Bigg|_{x-b}^{x-a}$$

$$\boxed{\varphi = k \lambda \left\{ \ln \left[ x - a + \sqrt{(x-a)^2 + y^2} \right] - \ln \left[ x - b + \sqrt{(x-b)^2 + y^2} \right] \right\}}$$

Okay, that's the potential. Now we have to take the gradient of it and evaluate the result at $y=0$ to get the electric field on the $x$ axis. We need to find

$$\vec{\mathbf{E}} = -\nabla \varphi$$

which, in the absence of any $z$ dependence, can be written as:

$$\vec{\mathbf{E}} = -\left( \frac{\partial \varphi}{\partial x} \hat{\imath} + \frac{\partial \varphi}{\partial y} \hat{\jmath} \right)$$

We start by finding $\frac{\partial \varphi}{\partial x}$:

$$\frac{\partial \varphi}{\partial x} = \frac{\partial}{\partial x} \left( k\lambda \left\{ \ln \left[ x - a + \sqrt{(x-a)^2 + y^2} \right] - \ln \left[ x - b + \sqrt{(x-b)^2 + y^2} \right] \right\} \right)$$

$$\frac{\partial \varphi}{\partial x} = k\lambda \left\{ \frac{\partial}{\partial x} \ln \left[ x - a + \left( (x-a)^2 + y^2 \right)^{\frac{1}{2}} \right] - \frac{\partial}{\partial x} \ln \left[ x - b + \left( (x-b)^2 + y^2 \right)^{\frac{1}{2}} \right] \right\}$$

$$\frac{\partial \varphi}{\partial x} = k\lambda \left\{ \frac{1 + \frac{1}{2} \left( (x-a)^2 + y^2 \right)^{-\frac{1}{2}} 2(x-a)}{x - a + \left( (x-a)^2 + y^2 \right)^{\frac{1}{2}}} - \frac{1 + \frac{1}{2} \left( (x-b)^2 + y^2 \right)^{-\frac{1}{2}} 2(x-b)}{x - b + \left( (x-b)^2 + y^2 \right)^{\frac{1}{2}}} \right\}$$
